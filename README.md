 # 💻 ALX Low-Level Programming - C Language

Welcome to the **ALX Low-Level Programming** repository! 🚀 This repository contains all the projects and exercises completed as part of the ALX Software Engineering program, focusing on the fundamentals of the **C Programming Language**.

---

## 📚 Repository Structure & Topics

Here is an overview of the directories and concepts covered in this repository:

| Directory | Topic / Focus Area |
| :--- | :--- |
| 🛠️ `0x00-hello_world` | Entry point, preprocessor, compilation stages (`gcc`), and basic printing functions (`printf`, `puts`). |
| 🔀 `0x01-variables_if_else_while` | Arithmetic operators, logical operators, `if/else` statements, and `while` loops. |
| 🔁 `0x02-functions_nested_loops` | Defining custom functions, header files (`main.h`), nested loops, and `_putchar`. |
| 🐛 `0x03-debugging` | Identifying bugs, testing edge cases, and fixing code logic (e.g., leap years, calendar calculations). |
| 🔣 `0x04-more_functions_nested_loops` | Advanced function usage, character checks (uppercase/lowercase), and printing patterns. |
| 📍 `0x05-pointers_arrays_strings` | Introduction to memory addresses, pointers, arrays, string manipulation, and utility scripts. |
| 🧵 `0x06-pointers_arrays_strings` | Advanced pointer arithmetic, multidimensional arrays, string operations, and security tasks. |

---
